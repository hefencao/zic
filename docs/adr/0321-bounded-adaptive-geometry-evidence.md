# ADR 0321：自适应页面几何使用一次性小样本判定

## 状态
Accepted。保留 ADR 0316 的“异常切片不能直接视为页漫”原则，并取代持续按已解码页面在线重算 profile 的聚合方式。

## 问题
model v6 已经把接近 1:1 的 transport slice 从强分页证据降为低信息，但仍把“偏离 1:1”近似对称地解释成页漫证据，
并且 Reader 每得到一个新的页面尺寸就重新计算 profile。

真机复现中，一个带 `韓國` 标签且来源条漫置信为 50% 的漫画实际出现 3 个 `720×500`，
随后大量 `720×700` transport slices。旧模型把 `720×500` 的横向比例当成分页证据，
而 `720×700` 虽然单页权重很低，持续追加样本仍会改变总分。最终 v6 持久化为
`LTR / page-geometry / 66.6% / 20 samples`，并在第 16 个尺寸样本时从 vertical fallback 翻成 paged。

这里有两个独立问题：

1. `720×500`、`720×700` 这类切片尺寸并不能证明“这是一个完整分页页面”，把“不是正方形”直接等价为页漫过强；
2. 布局类型是漫画级属性，没有必要随着 Reader 每解码一页持续重算。持续在线重算会让 profile 受预加载顺序、阅读进度与已解码页数影响。

## 决策
1. adaptive profile model 升为 v8；所有旧 model profile 继续沿既有 `isCurrent` 合同失效并重新分类。
2. 页面几何最多采样 **3 张**，包含第一页。第一页即使是封面，对“来源输出的是完整普通页面，还是异常 transport slices”
   仍然有几何信息，因此不再为了布局分类特意排除。
3. 达到目标样本数后只做 **一次** geometry decision，并停止接受新的 geometry sample。Reader 后续解码更多页面不得再次改变布局 profile。
   少于 3 页的章节直接使用全部页面；至少需要 2 张才允许几何分类。
4. `0.65 < height/width < 1.20` 定义为异常/切片不确定区，自身不给页漫几何票：
   - `720×700 ≈ 0.97` 属于此区；
   - `720×500 ≈ 0.69` 也属于此区。
   这不是把它们判成条漫，而是明确表示“这种 transport shape 不能证明页漫”。
5. 明显普通页漫形状才形成分页几何证据：
   - 足够宽的横页（`height/width <= 0.65`，例如 16:9）；
   - 普通竖页（`height/width >= 1.20` 且低于条漫过渡区，例如 9:16）。
   证据随离开不确定区的程度增强。
6. `1.9–2.2` 继续作为页漫/条漫过渡区；`>=2.2` 提供明确条漫证据，`>=3` 提供更强条漫证据。
7. 最多 3 张样本用于估计形状分布；几何总权重因此天然有界，避免持续解码更多页面机械扩大几何相对权重。
8. 元数据、typed source hint 与用户来源条漫置信仍是漫画/来源级证据，不按页面数缩放。
   50% 来源条漫置信继续表示真正的中性先验；`韩国/韓國` 继续只是弱条漫证据，不升级为硬方向规则。
9. Mihon bridge 当前统一投影 `readingDirection=vertical`，因此该字段不能作为自适应条漫证据，否则会把所有 Mihon 内容污染为条漫。
   自适应仍只消费明确 metadata、source adaptive hint、来源置信与有限页面几何。

## 后果
- 同一部漫画不会因为“看得越多 / 预加载得越多”从条漫突然翻成页漫。
- `720×500`、`720×700` 等异常切片在没有其它证据时保持不确定；带韩国/条漫相关 metadata 时，由 metadata 与其它独立证据决定。
- 普通 16:9、9:16 页面仍能在小样本内形成强页漫判断。
- 判定时间与已解码页数有明确上限，减少无意义的持续重算。
- 不新增来源特判、Reader owner 或持久设置；修复仍完全位于 `reader_runtime.AdaptiveReaderClassifier`。

## 真机验证（2026-09-24）
- 来源：肉漫屋，漫画《要成為男子漢》，来源条漫置信保持 50% 中性，漫画 metadata 含 `韓國`。
- 旧 model v6 曾在同一数据上持久化 `LTR / page-geometry / 66.6% / 20 samples`，并随着尺寸样本增加从 vertical 翻成 paged。
- model v8 的真实 APK 在同一设备重新进入 Reader 后持久化为 `vertical / 70.83% / page-geometry / samples=3 / modelVersion=8`。
- 继续停留 8 秒后 profile 仍为 `samples=3`；本漫画设置显示“条漫/纵向 · 71% · 页面比例”。
- 设备 trace 证明静止 Reader 仍可收到多于 3 个 `pageDimensionsResolved`，因此 samples 固定为3来自 classifier one-shot 边界，不是后续尺寸事件缺失。
