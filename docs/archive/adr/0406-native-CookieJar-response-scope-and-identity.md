# ADR 0406: Native CookieJar response scope and identity

Status: Accepted

## Context

An isolated Android application uses the actual installed WNACG 1.6 APK and
its original source client without explicit Cookie headers. Controlled responses
produce five failures: path leakage, Secure cookies on HTTP, expired cookies,
and lost same-name path identities. The shared AndroidCookieJar flattened
response Cookies to host/name/value. The existing explicit-header client
acceptance did not exercise this response-cookie path.

## Decision

Keep complete immutable OkHttp response Cookies in the existing adapter,
indexed by domain/name/path. Load only unexpired URL matches, longest path
first. Known cookie names within the applicable domain/path scope remain
authoritative over the asynchronous CookieManager mirror, including
expired/deleted identities. A known cookie at another path must not suppress
an unobserved same-name mirror cookie at the request URL.

Browser snapshots still contain host-scoped name/value pairs and import only
on a newer revision. Their current host-wide projection and paired UA remain;
this change does not add attribute capture to browser snapshots. CookieManager
headers do not identify domain/path attributes: an unknown same-name identity
overlapping a known scope cannot be distinguished from a delayed mirror.
Full cross-WebView cookie lifecycle acceptance remains open. Keep the
public adapter ABI, runtime/session lifecycle, source client, retry, request
plan, Reader/Pipeline, NetLane and durable resource identities unchanged.

## Validation

The real source-client probe records all requests before and after repair.
Production-executed checks use the actual OkHttp dependency with a delayed
Android mirror; eleven of the initial fourteen fail before repair. A fifteenth
check detects over-broad mirror suppression before the path boundary repair.
All fifteen final checks and nine real source-client assertions pass. Fresh
2321 Dart/Flutter tests, 27 analyzers, Rust22 and Android110 pass. Six ordinary
Profile/Release APKs retain all native and Dart libraries, the public CookieJar
ABI and other common-runtime class signatures; the common CookieJar asset
changes intentionally and its manifest matches generated bytes. Ordinary
Release validates grouped title search, JM WebView and cold tag query/response.
All125 full chapter payloads and67 read states remain exact. Full browser
attributes, overlapping unknown mirror identities and original Reader loading
remain open. Evidence: docs/archive/audits/mihon-CookieJar-boundary-2026-10-07.json.
